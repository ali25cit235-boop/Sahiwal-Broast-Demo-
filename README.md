# Sahiwal Broast - Kamalia (Sample Website)

A complete, premium, animation-rich sample website for **Sahiwal Broast** in Kamalia, District Toba Tek Singh, Punjab, Pakistan.

> **Notice:** This is only a sample website made by Ali Web Studio for presentation purposes only. Not the official website of the business.

---

## Features
- **Pure Static Site:** Built with vanilla HTML5, CSS3, and JavaScript. No build step, no npm, no backend, and works straight out of the box.
- **Categorized Food Photography & Building in `/sources`:** Real food photography and restaurant building exterior organized in the `/sources` directory for all dishes and premises (Building, Broast, Butter Karahi, Handi, BBQ platters, Rohu Fish, Zinger Burgers, Shawarma, Pizza, Pulao, Chowmein, Soups, Wings, Fries, Drinks).
- **Grand Restaurant Building & Ambiance Section:** Dedicated showcase for the restaurant's multi-story premises, AC family hall, road-front parking, and party booking.
- **Top 3 Featured Dishes Display:** Initially highlights the top 3 bestsellers with an interactive "View All Items" toggle for full menu browsing.
- **Interactive WhatsApp Ordering:** Instant WhatsApp order generator with cart management, pricing calculations, item quantities, and customer details.
- **Motion & Micro-interactions:** Smooth preloader, GSAP ScrollTrigger reveals, 3D tilt deals cards, infinite marquee ticker, counter animations, and mobile drawer.
- **Mobile First & Responsive:** Optimized for all screen sizes, from 360px phones to large desktops.

## Deploy on Cloudflare Pages
Deploying this project to Cloudflare Pages takes less than 60 seconds:

1. Push or import this repository to GitHub.
2. In Cloudflare Dashboard, go to **Workers & Pages** > **Create application** > **Pages** > **Connect to Git**.
3. Select your repository.
4. Set the build configuration:
   - **Framework preset:** None
   - **Build command:** *(leave empty)*
   - **Build output directory:** `/`
5. Click **Save and Deploy**.

The site will be live on your custom `*.pages.dev` domain immediately!
